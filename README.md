# QTForming: Thermoformed Inserts

![qtforming](https://github.com/user-attachments/assets/eaf5f4fb-ab47-4b1d-ba75-6b9a8085d521)

QTForming (QuasiThermoforming) introduces a “one-size-fits-all” concept for inserts, in which a basic shape is created using sparse infill and then thermoformed to match the shape of an object.
